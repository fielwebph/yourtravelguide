# Vehicle photos

Drop a photo in here using the exact filename below and it appears on
`terms.html` automatically — no code change needed. Until a file exists, that
slot falls back to its "Photo to be added" placeholder, so nothing ever looks
broken. This is the same pattern `assets/destinations/` uses.

The files already here are the branded YTG vehicle cards, resized to 900×900
and saved as JPEG so each one stays around 110 KB.

## What to supply

- **Shape:** Vehicle Types slots are square (the branded cards are 1:1).
  "Our Vehicles in Action" tiles are 1:1 on phones and 4:3 on wide screens.
- **Size:** 900×900 for vehicle cards, around 800×600 for gallery tiles.
- **Format:** `.jpg`. To use `.webp` or `.png` instead, update the `src` on the
  matching `<img>` in `terms.html`.
- **Weight:** aim under ~200 KB each. There are a lot of slots on this page.

## Licensing

Use photos you own or that are licensed for commercial use — this is a
commercial site.
