# Vehicle photos

Drop a photo in here using the exact filename below and it appears on
`terms.html` automatically — no code change needed. Until a file exists, that
slot falls back to its "Photo to be added" placeholder, so nothing ever looks
broken. This is the same pattern `assets/destinations/` uses.

## What to supply

- **Shape:** Vehicle Types cards crop to 16:10. "Our Vehicles in Action" tiles
  crop to 1:1 on phones and 4:3 on wide screens, so keep the vehicle centred.
- **Size:** around 1000×625 for vehicle cards and 800×600 for gallery tiles.
- **Format:** `.jpg`. To use `.webp` or `.png` instead, update the `src` on the
  matching `<img>` in `terms.html`.
- **Weight:** aim under ~200 KB each. There are a lot of slots on this page.

## Licensing

Use photos you own or that are licensed for commercial use — this is a
commercial site.

## Changing the alt text

Each `<img>` in `terms.html` has a generic `alt`. Once you know what the photo
actually shows, make it specific — "Toyota Alphard at Haneda Airport arrivals"
beats "7-Seater vehicle used for private transfers and tours in Japan".
